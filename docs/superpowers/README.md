# Design records index

This indexes the design records under `docs/superpowers/`: specs, plans, and research notes written as the system grew past the founding compendium in `docs/DESIGN.md`.

- **Specs** — A spec records a design DECISION — what was decided, and why — before or alongside the code that implements it.
- **Plans** — A plan records the task-by-task IMPLEMENTATION of a decision, usually a spec's.
- **Research** — Research records an evidence base or a design question worked through before a decision was ready to write down as a spec.

**Status vocabulary** (exactly these five words, one per record, in that record's own `> **Status:**` header): `diverged`, `implemented`, `open`, `partial`, `superseded`.

> Generated by `scripts/gen_records_index.py` — do not hand-edit. The header in each record (`> **Status:** ...` / `> **As-built:** ...`, right after its title) is the source of truth; re-run the script after changing a header.
