# Archive

Records kept for their history. **Nothing in this folder is current**: read it
as a record of what was intended or decided at the time, never as a statement
of how the system works or what it must do. The current layers are
[`../PRD.md`](../PRD.md) (why and what), [`../ARCHITECTURE.md`](../ARCHITECTURE.md)
(how, as built) and [`../decisions/`](../decisions/README.md) (why behind each
rule).

| file | what it is |
|------|------------|
| [`DESIGN.md`](DESIGN.md) | the founding design, frozen as a record (DL-185) |
| [`superpowers/`](superpowers/) | design records whose status header is `superseded`, moved out of `docs/superpowers/` |
| [`decisions-archived.md`](decisions-archived.md) | decision-log entries enforced by discipline only and cited nowhere else; each keeps a one-line stub, and its id, in its area file |

Files here are moved with `git mv`, so `git log --follow` shows their history.
