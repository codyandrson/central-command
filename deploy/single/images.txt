# deploy/single/images.txt — THE image manifest for the single-node profile.
#
#   Every image this profile pulls, pinned by DIGEST. `setup.sh fetch` pulls
#   each one as <ref>@<digest> (so the mirror cannot serve a poisoned or
#   drifted tag) and then tags it <ref> locally; the templates reference
#   <ref> by tag and never trigger a pull. `bundle.sh export` saves the same
#   list. The digest lives HERE and not in the templates because a
#   docker-archive round-trip (bundle export/import) does not preserve the
#   manifest-list digest — a `tag@digest` reference in a template would
#   resolve on the mirror path and fail on the bundle path.
#
#   Columns:  <registry-key> <path:tag> <digest> <component>
#     registry-key  dockerio | ghcr | mcr  → CC_REGISTRY_DOCKERIO / _GHCR / _MCR
#     component     core | n8n | graphiti-base | sandbox-base | crawler-base
#                   (fetch skips components whose CC_ENABLE_* flag is 0)
#
#   Bumping a line is a deliberate act — a release — never a side effect of
#   what the mirror happens to hold today. Resolve a new digest with:
#     curl -sI -H 'Accept: application/vnd.oci.image.index.v1+json, application/vnd.docker.distribution.manifest.list.v2+json' \
#       https://<registry>/v2/<path>/manifests/<tag> | grep -i docker-content-digest
