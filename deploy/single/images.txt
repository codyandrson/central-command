# deploy/single/images.txt — THE image manifest for the single-node profile.
#
#   Three tiers, not one pin (design record
#   docs/superpowers/specs/2026-09-03-deploy-refactor-design.md, D2). Rigid
#   @sha256 pinning broke real installs when an enterprise mirror lacked the
#   exact artifact, so each image now carries the loosest TRUE requirement
#   (the constraint) alongside the tested tag+digest (the lock):
#
#     constraint   the tag SERIES this release supports — a floor AND a
#                  ceiling, never a bare floor (a new major is a breaking
#                  change until proven otherwise)
#     lock         the tag and digest this release was tested against
#
#   `resolve-images.sh` asks the (mirror) registry what it actually has:
#   the locked tag → PASS (and the pulled digest must match this one); else
#   the newest tag satisfying the constraint → WARN naming the substitution
#   (no digest check — a substituted tag is trusted from the enterprise
#   mirror; the digest pin defended against public-registry tag poisoning, a
#   threat the mirrored air gap does not carry); else FAIL. The resolved refs
#   are written to .env as CC_IMG_* and compose.yaml reads them.
#
#   Columns:  <registry-key> <path> <constraint> <locked-tag> <locked-digest> <component>
#     registry-key  dockerio | ghcr | mcr  → CC_REGISTRY_DOCKERIO / _GHCR / _MCR
#     path          the repository path, WITHOUT a tag
#     constraint    the VERSION SERIES only (16, 5.26, 7, main-stable): a tag
#                   fits when it equals it or continues it at a non-digit
#                   (16 admits 16.10, not 160). The FLAVOUR comes from the
#                   locked tag and a substitute must keep it: 7-alpine admits
#                   7.4-alpine and rejects 7.4 and 7.4-alpine3.22; 16 rejects
#                   16.10-alpine3.22; 5.26.2 rejects 5.26.4-enterprise.
#     locked-digest what the locked tag must hash to, or `-` when the tag is
#                   ROLLING (a series or a channel: 16, 7-alpine, main-stable).
#                   Those move on every upstream rebuild, so the TAG is the pin
#                   and a digest there would fail weekly on a healthy registry.
#                   An exact-version tag gets a real digest, and a mismatch on
#                   one is a hard FAIL.
#     component     core | n8n | graphiti-base | sandbox-base | crawler-base | speech
#                   (resolution skips components whose CC_ENABLE_* flag is 0)
#
#   The CC_IMG_* variable name is derived from the path: uppercase, `/` and
#   `-` become `_`, a leading `LIBRARY_` is dropped. library/postgres →
#   CC_IMG_POSTGRES, playwright/python → CC_IMG_PLAYWRIGHT_PYTHON.
#
#   Bumping a lock is a deliberate act — a release — never a side effect of
#   what the mirror happens to hold today. Resolve a new digest with:
#     curl -sI -H 'Accept: application/vnd.oci.image.index.v1+json, application/vnd.docker.distribution.manifest.list.v2+json' \
#       https://<registry>/v2/<path>/manifests/<tag> | grep -i docker-content-digest
#   (docker.io needs a bearer token from auth.docker.io first.) Locked 2026-08-30.
