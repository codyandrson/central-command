# Tombstones: resources whose manifest was removed from deploy/k3s/.
# Plain `kubectl apply -f <dir>` never deletes anything, so a resource
# outlives its manifest unless it is named here — cc-update.sh deletes each
# line (idempotent: --ignore-not-found) in the manifests phase.
# Removing a manifest from this directory means adding its line here.
# Format: <namespace> <kind> <name>
central-command deployment cc-adminer
# Design record 2026-10-04, D10: the Graphiti MCP server left the
# deployment — graphiti-core runs inside the control plane now. Its Deployment
# and Service were tombstoned in v2.60.0; its configmap (cc-graphiti-config)
# and Secret (cc-graphiti) follow here one release LATER, because the previous
# updater's rollback re-applies the previous manifests, which recreate the
# Deployment but not these two (make-secrets.sh made them), so deleting them a
# release earlier would have left a rolled-back graph server unable to start.
# make-secrets.sh no longer creates either.
central-command deployment cc-graphiti
central-command service graphiti
central-command configmap cc-graphiti-config
central-command secret cc-graphiti
